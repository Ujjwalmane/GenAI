# AI-Powered Meeting Minutes and Action Item Generator

A sample Generative AI system that turns a meeting transcript into structured minutes, decisions, and trackable action items.

## Project contents

- `meeting_minutes_report.md` — Sample transcript, summarization prompt, meeting summary, decisions, action items, owners, deadlines, and accuracy check.

## Features

- Includes a 30-statement sample meeting transcript.
- Provides a prompt for summarizing the discussion and extracting action items.
- Records decisions with any conditions attached.
- Lists each action with its responsible person and deadline.
- Checks extracted information against transcript statement numbers.

## How to use

1. Open `meeting_minutes_report.md`.
2. Review the sample transcript.
3. Apply the included prompt to a new meeting transcript.
4. Check the generated summary, decisions, owners, and deadlines against the source transcript.

## Requirements

No software installation is required to read the report. To generate minutes from another transcript, use a Generative AI tool that can follow the included prompt.

## Sample output

The report includes:

- Meeting summary
- Key decisions
- Action items and responsibilities
- Deadlines
- Accuracy verification
